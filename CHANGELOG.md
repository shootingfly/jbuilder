# Changelog

## 1.1.0 - 2026-11-21

- Add compiled partial templates with explicit locals and isolated scopes.
- Reject missing, unknown, duplicate and runtime partial arguments at compile time.
- Render parsed values and nested arrays, tuples, hashes and named tuples natively.
- Preserve existing builder, layout and embedded-template behavior.

## 1.0.0

- Support Crystal 1.0.0.
